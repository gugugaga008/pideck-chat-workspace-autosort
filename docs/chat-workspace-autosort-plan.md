# 聊天工作目录自动分类实施计划

状态：实现与验证完成；尚未写入真实安装目录（需要用户先完全退出 PiDeck）。基线：PiDeck v0.12.0（cf57f7f0012f7a30431ac6164802eb1e08bab843）。

## 范围

- 原聊天根目录保持 `C:\Users\MSI-1\AppData\Roaming\PiDeck\chat-workspace`，不移动或清理现有文件。
- 新增显式授权的 `chatWorkspace.manage` 插件权限，仅允许读取状态和修改 enabled 开关。禁止任意路径、通用文件系统、RPC 或会话修改能力。
- 自动分配由主进程服务执行，面板关闭也有效；配置原子持久化。
- 第一版支持内置聊天项目、原生 Windows/本机 pi 后端。其他后端和远端保持现状并在说明中标识范围。
- 每个新会话绑定一个原根下的 `YYYY-MM-DD/意图--唯一ID` 子目录，保存到 catalog；恢复使用原绑定，不随标题和日期变化。
- pi 自己管理聊天日志，宿主不改写活跃 JSONL。
- 旧会话继续使用原目录；禁用只影响之后的新会话，已绑定目录继续沿用。

## 交付

1. 可审查的 PiDeck 源码改动与针对性行为测试。
2. 独立静态宿主插件设置面板。
3. 安装版本检查、备份、适配恢复与回滚工具（不自动关闭用户进程）。
4. 使用说明和已知兼容边界。

## 验收

已完成：不同会话同名产物隔离；并发首次发送只绑定一次；重启/跨日/改标题目录稳定；旧会话不迁移；standby 不复用错误 cwd；插件撤权与非法输入拒绝；未知版本拒绝自动修改；恢复不触碰用户聊天/产物数据。

打包后 smoke 在完整程序副本中通过，证据见 `verification/smoke-result.json`。真实安装目录当前仍为 `clean`，未写入。

## 升级边界

用户数据与功能源码保存在安装目录之外。适配工具仅处理已验证的版本与归档指纹；未知版本明确停止自动适配。接口尚未合入官方，不承诺所有未来版本零维护，也不自动提交或发布远端内容。
